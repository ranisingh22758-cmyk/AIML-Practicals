
# AIML Practicals

A collection of Artificial Intelligence and Machine Learning practical assignments implemented using Python and Jupyter Notebook.

## Project Overview

This repository contains practical implementations of machine learning algorithms and data analysis techniques using a student performance dataset. The assignments cover data analysis, dimensionality reduction, classification, regression, and clustering.

## Assignments Included

| Assignment | Topic | Technique |
|---|---|---|
| 1 | Association and Correlation Analysis | Correlation Matrix and Heatmap |
| 2 | Clustering | K-Means Clustering |
| 3 | Dimensionality Reduction | Principal Component Analysis (PCA) |
| 4 | Classification | Gaussian Naive Bayes |
| 5 | Classification | K-Nearest Neighbors (KNN) |
| 6 | Regression | Linear Regression |
| 7 | Classification | Decision Tree |
| 8 | Classification | Random Forest |
| 9 | Classification | Support Vector Machine (SVM) |
| 10 | Clustering | K-Means Clustering |

## Dataset

**File:** `Student_Performance_Dataset.csv`

The dataset contains 200 student records with features such as:

- Study Hours
- Attendance Percentage
- Previous Marks
- Sleep Hours
- Assignment Score
- Final Marks
- Performance Category

The dataset is synthetic and intended for educational and practical learning purposes.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Scikit-learn

## How to Run

1. Clone or download this repository.
2. Install Python and Jupyter Notebook, or use Anaconda Navigator.
3. Install the required libraries:

   ```bash
   pip install pandas matplotlib scikit-learn
   ```

4. Open Jupyter Notebook in the repository folder.
5. Open any assignment notebook (`.ipynb`).
6. Run the notebook cells from top to bottom.

Keep `Student_Performance_Dataset.csv` in the same folder as the notebooks.
